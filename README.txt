اپ مدیریت شخصی معاون فنی هنرستان - نسخه موبایل V2

نکته مهم:
- اطلاعات داخل مرورگر همان گوشی ذخیره می‌شود.
- از بخش «پیگیری‌ها > پشتیبان‌گیری» می‌توانید فایل JSON پشتیبان بگیرید.
- فایل پشتیبان را در Files / iCloud Drive / Google Drive نگه دارید.
- برای بازیابی، همان بخش را باز و فایل JSON را انتخاب کنید.

برای نصب مثل اپ واقعی:
این پوشه باید روی یک آدرس HTTPS میزبانی شود. سپس:
Android/Chrome: منوی مرورگر > Add to Home screen / Install app
iPhone/Safari: Share > Add to Home Screen

اگر فقط index.html را مستقیم از Files باز کنید، بعضی مرورگرهای موبایل اجازه ذخیره‌سازی پایدار یا نصب PWA نمی‌دهند؛ استفاده از HTTPS مطمئن‌تر است.
